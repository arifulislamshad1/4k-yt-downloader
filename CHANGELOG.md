# Changelog

All notable changes to this project are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0.0] - 2026-11-16

### Added
- Chrome and Edge extension with download controls on YouTube and other video sites
- Local helper with download queue, pause, resume, retry, cancel and playlist support
- Automatic helper start through native messaging
- Automatic yt-dlp update and retry on site changes
- Per-user Windows installer
