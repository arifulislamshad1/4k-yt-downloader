# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Use the **Report a vulnerability** button on the repository's **Security** tab to send a private report.
Include the affected version, steps to reproduce and the potential impact.

## Scope

- The helper's local HTTP interface on `127.0.0.1:9777`
- The native messaging host and its registration
- Extension permissions and content scripts
- The build and installer scripts

Issues in yt-dlp, FFmpeg or Deno should be reported to those projects.
